# Introduction

A versioned JSON:API style REST API for raising, assigning, filtering and resolving support tickets, secured with JWT and token abilities.

<aside>
    <strong>Base URL</strong>: <code>http://localhost:8000</code>
</aside>

    This documentation describes version 1 of the Ticket Management API (every URL starts with `/api/v1`). Log in with the manager account `manager@manager.com` / `password` (created by `php artisan db:seed`) to try every endpoint.

    <aside>As you scroll, you'll see code examples for working with the API in different programming languages in the dark area to the right (or as part of the content on mobile).
    You can switch the language used with the tabs at the top right (or from the nav menu at the top left on mobile).</aside>
